# VECTOR — source capture

Source: [Matt Pocock on X](https://x.com/mattpocockuk/status/2123810087361810663), 20 November 2026. Captured via FxTwitter and the attached image; this is a paraphrase, not a transcript.

Pocock introduces a forthcoming `/vector` skill intended to help non-developers delegate tasks to AI. He plans frameworks and documentation for organizational sessions covering workflow discovery, context, reordering work, and learning through memory.

The diagram calls the method “mapping a workflow onto an agent.” It suggests starting with an existing workflow taking at least 20 minutes, then asking six questions in order: verification, existing process, context, trust, order, and remember. The intended output is a workflow map covering completion checks, steps and inputs, delegation, human–agent turns, and memory between runs.
